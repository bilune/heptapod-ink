The objections are concrete:

- `load_rows(split)[:n]` selects a prefix, not a randomized representative sample. At n=100, uncertainty is substantial. R=6 and R=20 have different unchanged-writer baselines; rounds cannot cause that. Record checkpoint/data hashes, item IDs, device/precision and predictions, then rerun paired budgets. Lower NLL can also worsen greedy decoding.
- The script omits `export_image/save_png/load_png` and `channel`. Existing 400/400 PNG agreement concerns original codes. Test searched codes through actual 16-bit export/reload, separately through 8-bit conversion and deployment-relevant perturbations. Search changes neighboring-mark combinations; original average eyes accuracy cannot certify these.
- “Words” is positional accuracy: trailing insertions escape penalties. Add WER, cased exact, length/rarity strata, and paired sentence-bootstrap intervals. `MAX_T=40` truncates both source and objective; report overflows as failures separately.
- Sum of marginal entropies is an upper bound on joint entropy, not usable information. Correlation can consume the apparent 201-bit headroom. Search demonstrates an encoder optimization gap, analogous to [amortization suboptimality](https://proceedings.mlr.press/v80/cremer18a.html), not proof that capacity never binds.

Tune on dev; freeze the protocol before a fresh holdout. Use new-seed random combinations, excluding known training/evaluation strings; acknowledge that unlogged historical random samples prevent exhaustive exclusion. Natural holdout sentences should have been added after the original download, deduplicated against prior corpora. Shuffling searched images must destroy reconstruction.

My concrete search starts with gradient-shortlisted hard coordinate descent, keeping the original code as fallback. Differentiate symbolic source NLL with respect to slot embeddings; rank all 36×80 substitutions by `gradient·(new−current)`. Exactly score 16 distinct proposals, including nearest-centroid alternatives; render the best four. Recompute gradients after each accepted move. This escapes the script’s fixed nearest-eight restriction without scoring every neighbor. [Neural-codec inference optimization](https://arxiv.org/abs/2006.04240) supports optimizing discrete latents at encoding time; its stochastic annealing is a later comparison, not evidence it beats this measured baseline.

For each finalist define `ell_j = −log p(source | eyes(T_j(PNG(render(code)))))/tokens`, including EOS. Minimize `J = mean_j(ell_j) + 0.5 max_j(ell_j)` over four fixed views: clean PNG plus three seeded channel perturbations. Calibrate perturbation ranges on train-only deployment samples. This preserves overlapping-mark dependencies that independent confusion sampling misses; refreshed confusion is only a cheap surrogate. Accept J improvements only if clean free-decoding edit distance does not worsen. Stop after eight rounds, two stalled rounds, or exact decoding on all views; retain the best accepted code. Final evaluation uses unseen perturbations. [Expectation over transformations](https://arxiv.org/abs/1707.07397) can also produce robust adversarial examples: this is empirical robustness, not an “adversarial-free” guarantee.

The original R=20,K=8 costs up to 5,760 candidate sequence scores/example. Proposed eight-round search costs roughly 128 symbolic plus 128 visual scores, eight backward passes, and acceptance/final greedy decodes, excluding initialization. Batch candidates and sentences; benchmark seconds/example and peak memory. These counts are not wall-time speedup claims. Try beam width two only after this passes; it approximately doubles search work. Fixed transforms, tie-breaking and precision are necessary for reproducible redraw verification, which multiplies sender cost by candidate count. Defer beam-32 verification.

Amortization is sound: [Expert Iteration](https://arxiv.org/abs/1705.08439) alternates search and policy learning. Generate train-only targets with 50% natural/50% random inputs, retaining improvements and successful originals, not just easy exact cases. Freeze books, mark mapping, eyes, adapter and reader. Train encoder/writer using slot CE on `softmax(−distance/tau_s)` toward one canonical searched code, plus hard-forward STE text CE through the frozen reader. Start equal loss weights, average CE per slot/token, calibrate temperatures on training data, and use 20% original-code replay. AdamW: writer 3e−4, encoder 2e−5, batch 64, clipping 1; BF16 with FP32 distances. Never average incompatible successful code sequences or update EMA beneath cached targets. Evaluate hard visual outputs, not imitation accuracy alone. Refresh targets from the student once; retain old better targets. [Iterative amortized inference](https://proceedings.mlr.press/v80/marino18a.html) motivates a learned refinement loop if direct distillation fails, but adds engineering beyond this first budget.
