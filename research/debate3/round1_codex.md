**1. Diagnosis**

Fix the learned code before replacing the eyes. Continuous slots achieved 99% exact; quantized visual decoding gives natural 62.7% exact/88.2% words, random 9.2%/44.1%. Symbolic decoding adds only ~2 points. Verification reaches 88.2% natural exact but only 48.3% random words; random candidate recall is 30%. Wider beams cannot distinguish identical codes.

The ceiling is 36·log₂81=228.2 bits, not measured information. A slot using 10–12 marks has at most 3.32–3.58 bits versus 6.34; correlations further reduce joint entropy. Measure hard per-slot entropy, conditional predictability, and code collisions. The 22% beam-collision rate demonstrates local ambiguity, **not saturation of all 228 bits**; deduplicate normalized candidates and distinguish code equality from pixel equality.

Ten uniform 32k words require ~150 bits. I calculated 13.85 bits/word from `random_vocab.json`’s actual weights: ~138.5 bits for ten independent draws, excluding framing. Rare words remain expensive, unpredictable, and often span multiple T5 tokens. Semantic substitutions suggest lexical distinctions lost during quantization plus decoder-prior bias. Euclidean centroid fitting need not preserve spelling distinctions; teacher-forced CE can reward predicting common continuations instead. `MAX_T=40` silently truncates inputs/targets: audit overflow separately.

Stage 1 still uses the stage-0 ~91% channel despite final 99.1%/98.1% eyes. As an illustrative independent symmetric-channel calculation, 9% versus 1.9% errors allow ~192 versus ~219 bits/ring. These are not measured capacities. At 98.1%, only ~50% of rings have all 36 marks correct under independence: preserve robustness.

**2. Ranked options**

Forecasts below are **subjective, non-additive percentage-point gains** in random word accuracy/natural exact over **44.1%/62.7%, greedy visual**. Costs are estimated H100 minutes including brief adaptation/evaluation, excluding implementation. Papers establish mechanisms elsewhere, not these gains. Each M4 probe uses train-only fitting and held-out dev evaluation.

1. **Calibrated continuation: +3–10/+2–6; 20–45 min.** Retain [VQ-VAE](https://arxiv.org/abs/1711.00937), EMA and existing entropy loss. Compare unchanged continuation against freshly measured writer-conditioned confusion, using clean-plus-augmented renders; retain 50% random training. Local entropy rescue already improved random words ~33→43%, so continuation has evidence. Risk: undertraining robustness or ignoring newly activated marks. M4: two matched 200-update branches; reject recalibration without better clean *and* noisy random decoding; periodically refresh coverage.

2. **Rotation gradients: +5–15/+3–10; 30–60 min.** Replace identity STE with detached rotation/rescaling from encoder vector to selected centroid; keep hard forward, books, EMA and entropy unchanged. [Rotation trick](https://arxiv.org/abs/2410.06424) improves utilization and reconstruction across VQ settings. Risk: near-zero norms and unsuitable gradient geometry. M4: verify identical hard outputs, finite gradients, then matched 300-update STE/rotation branches; reject without held-out reconstruction gain, regardless of utilization.

3. **Writer-side code search, unconventional: +3–12/+2–8; 0 training min.** Following [content-adaptive compression](https://arxiv.org/abs/1906.01223), freeze weights; use gradients to shortlist single-slot substitutions, evaluate hard candidates by source-text CE, and accept only improvements confirmed by free decoding through rendered ink. Sender knows the source; receiver sees pixels only. Risk: latency, teacher-forcing shortcuts, adversarial codes. M4: 64 unseen sentences, ≤32 search rounds; reject below +5 random-word points. Existing redraw verification must use this same deterministic searched writer. It cannot repair previously drawn rings.

4. **Expand observable alphabet: +10–25/+5–15; 100–195 min.** Move each nonblank mark inside/outside the same fixed ring: 80×2+blank=161 distinct symbols, ~264 bits. Four distinguishable variants yield 321/~300 bits. Reinitialize expanded books from continuous activations; retrain eyes. [SoundStream](https://arxiv.org/abs/2107.03312)/[EnCodec](https://arxiv.org/abs/2210.13438) justify residual quantization only when every residual index is transmitted: two nine-entry books still give 81 combinations. Risk: overlap, radial cropping, indistinguishable mirrors/scales. M4: render variants, detect raster duplicates, train a small recognizer; reject if held-out slot accuracy cannot approach 98%. Geometry changes explicitly.

5. **SimVQ rescue: +4–14/+2–9; 35–70 min.** [SimVQ](https://arxiv.org/abs/2411.02038) freezes coefficient vectors and learns a common linear transform, coupling code updates. Proposed warm-start variant: per-slot C=current books, W=identity; disable EMA, add codebook regression loss, learn W. This preserves initial decoding but differs from paper initialization. Risk: preserving existing degeneracy; entropy alone cannot guarantee lexical information. M4: compare with EMA for 300 updates; reject without hard reconstruction gains and reduced collision frequency.

6. **Adaptive residual messages plus teacher: +5–20/+3–12; 60–120 min.** Train 24 coarse slots plus 12 refinement slots, supervised by CE and output-logit distillation from the 99% continuous teacher. Learned routing focuses refinement on poorly reconstructed tokens; explicit blank/occupancy carries allocation. [Discrete communication](https://arxiv.org/abs/1705.11192) supports learned protocols, not guaranteed verbatim reconstruction. Risk: coarse channel loses too much; routing metadata consumes capacity. No extra nominal bits. M4: 256-example overfit and unseen rare-word substitutions; reject if refinements fail to improve free decoding over the coarse code. Never pass teacher states to the reader.

7. **LM entropy coding, unconventional: +0–40/+0–30; 40–100 min.** [LM compression](https://arxiv.org/abs/2309.10668) and EnCodec motivate a causal learned prior plus arithmetic coding. Compress a richer latent stream into ≤228 bits, including length/error protection; compressing the existing lossy code cannot recover discarded words. A code prior must condition only on already decoded symbols; the text-conditioned reader is circular. Rare random words receive more bits, not free prediction. Risk: overflow and catastrophic desynchronization. M4: measure held-out total codelength quantiles and exact bitstream round trips first. Arithmetic packing is an explicit exception to strict “trained models only”; otherwise diagnostic only, with zero deployment gain.

8. **Analog residual ink, unconventional: +10–35/+5–20; 80–160 min.** Add learned bounded thickness/gray modulation; train writer→renderer→eyes→decoder jointly with continuous-teacher distillation and raster noise. [Deep JSCC](https://arxiv.org/abs/1809.01733) supports continuous channel learning, not lossless guarantees. Risk: overlap, fragile precision, saturated rendering gradients; 99% mark recognition says nothing about analog SNR. M4: learn amplitude recovery on overlapping random rings, then reconstruct 256 texts; reject gains disappearing after 8-bit PNG, resizing, or noise. This changes the channel; continuous slots alone are not evidence of success.

**4. Uncertainty and exclusions**

Unknown: joint code entropy, truncation frequency, correlated visual errors, teacher availability, throughput, and transfer of image/audio quantizers. [FSQ](https://arxiv.org/abs/2309.15505) already failed locally; [LFQ](https://arxiv.org/abs/2310.05737)/[BSQ](https://arxiv.org/abs/2406.07548) need observable binary alphabets, not invisible extra bits. [Semantic hashing](https://www.cs.toronto.edu/~hinton/absps/sh.pdf) favors similarity over wording; [Donut](https://arxiv.org/abs/2111.15664) targets reading, already strong here. [Deepcode](https://arxiv.org/abs/1807.00801) assumes feedback absent from a static ring. None warrants a blind restart.
